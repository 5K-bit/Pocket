Pocket 0.2.0 is a polish release of the static launcher: new default shortcuts (THE LINK, CityGrid, Supabase), a corrected OBEOS site address, an iPhone install tip, a friendlier link editor and larger tap targets.

**Pre-release.** Desktop-browser verified; iPhone verification is a manual step (see `docs/runbook.md`).

### Known limitations
- Not tested on iOS Safari or an installed Home Screen app.
- Service worker registers only on HTTPS.
- Destinations are not encrypted, backed up or synced. No service health, authentication or notifications.
